# FitPulse (APP)

Kompletna aplikacija u jednom folderu — trening, tier, dostignuća, toast notifikacije (stack).

## Pokretanje

```bash
cd c:\Users\user\Desktop\APP
npm install
npm run dev
```

## Struktura

- `src/App.jsx` — glavna aplikacija
- `src/components/ToastQueue.jsx` — notifikacije (više odjednom)
- `src/utils/theme.js` — tier, XP, dostignuća
